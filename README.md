# packtrace

Pack identifiers and trace tokens for idempotent workflows.

**Site:** https://theworker02.github.io/packtrace/

## Install / run

```bash
git clone https://github.com/theworker02/packtrace.git
cd packtrace
node src/cli.js
node --test
```
